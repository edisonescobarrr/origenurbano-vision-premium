# ARQUENO

Sitio web de ARQUENO, inmobiliaria especializada en compra, venta y arriendo de vivienda urbana en Colombia.

**Sitio en producción**: https://arqueno.com

## Stack

- Vite + React + TypeScript
- Tailwind CSS + shadcn/ui
- Supabase (base de datos, almacenamiento de archivos y autenticación por correo)
- Resend (envío de correos transaccionales)

## Desarrollo local

Requiere Node.js y npm.

```sh
git clone git@github.com:edisonescobarrr/origenurbano-vision-premium.git
cd origenurbano-vision-premium
npm i
npm run dev
```

Copia `.env.example` a `.env` y completa las credenciales de Supabase antes de correr el proyecto.
